الخصوصية

الكاميرا والمايكروفون يعملان فقط بعد موافقة المستخدم. الصور والفيديوهات تبقى على جهازك ولا يتم رفعها إلى خادم خارجي بواسطة التطبيق. يتم تخزين الوسائط محليًا داخل متصفحك باستخدام IndexedDB، ويمكنك حذفها في أي وقت. عند فتح التطبيق يتم طلب الأذونات تلقائيًا لتسريع التجربة.

العلامة المائية

كل صورة يتم التقاطها تحمل علامة مائية مميزة بشعار MAZO CAMERA في الزاوية السفلية اليسرى، بتصميم أنيق لا يؤثر على جودة الصورة.

التقنيات المستخدمة

HTML5 · CSS3 · JavaScript (Vanilla)
getUserMedia · MediaRecorder · Canvas 2D · IndexedDB · Web Share API

حدود تقنية حقيقية (بدون ادّعاءات)

• التحكم في الفلاش (Torch) والتركيز اليدوي والتعريض الحقيقي يعتمد على دعم الجهاز والمتصفح. عند عدم التوفّر يستخدم التطبيق بدائل برمجية (Canvas / CSS) ويوضّح ذلك.
• توازن اللون الأبيض و"التثبيت" يتمّان كمحاكاة لونية وليست تحكمًا في العتاد.
• الصيغ المتاحة للتسجيل تُحدَّد عبر MediaRecorder.isTypeSupported().
• بعض المتصفحات (خاصة iOS Safari) لا تسمح بطلب أذونات الكاميرا/المايكروفون دون تفاعل مباشر من المستخدم، لذا يظهر زر احتياطي "تشغيل الكاميرا".
• التطبيق لا يستطيع تثبيت نفسه كـ PWA كاملة من ملف واحد (يحتاج manifest و service worker منفصلين).
